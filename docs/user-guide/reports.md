# Reports & Insights

## Daily Digest

If your admin has enabled Daily Digest, you'll receive an AI-generated summary every day at a scheduled time in a designated channel. It covers:

- Number of tasks completed
- Peak activity hours
- Stalled task status

---

## Weekly Report

If your admin has enabled Weekly Reports, a 7-day communication summary is generated each week. View it at **Insights → Reports → AI Weekly Work Insights**.

Includes: weekly task summary, communication relationship chart, channel distribution.

---

## AI Report (Custom Date Range)

Generate an on-demand AI report for any date range:

1. Go to **Insights → Reports** → click **New Report**.
2. Select a **start date** and **end date**.
3. Click **Generate & Analyze**.
4. The report is generated asynchronously — it will appear in the report list when ready.

> [!NOTE]
> If the selected period has a lot of data, some older messages may be skipped due to token limits. A notice will appear in the report if this happens.

**Options inside a report:**

| Feature | Description |
|---|---|
| **Translate** | Translate the report into another language (original is preserved) |
| **Export to Notion** | Send to a Notion page (requires admin to set up Notion integration) |
| **Delete** | Remove the report |

## Insights Statistics

Go to **Insights → Statistics**:

| Metric | Description |
|---|---|
| Total Completed | All-time task completion count |
| Peak Focus Hours | Your most productive time of day |
| 30-Day Activity | Heatmap of daily completions |
| Hourly Activity | Line chart |
| Channel Distribution | Pie chart |
| Completion Trend | 1-month / 3-month / 1-year filters |

---

## Token Usage

Check your Gemini AI usage at **Settings → Token Usage Monitor** or the AI Usage card in **Insights → Statistics**.

Shows today and this month's token consumption and estimated cost, broken down by analysis vs. translation.
